===========================================================
  CrossPointer 🎯 极简屏幕十字辅助线 - 快速使用指南 (v1.4)
===========================================================

【软件定位】
CrossPointer 是一款参考 macOS 26 设计美学的极简、超低资源占用的
Windows 屏幕十字辅助线工具，专为数据审阅、代码对齐、设计参考而设计。
本软件为 100% 纯绿色便携软件：
- 解压即用，无需安装。
- 零注册表垃圾，零外部临时文件残留。
- 产生的所有配置文件（CrossPointer.ini）均保存在本文件夹内。

-----------------------------------------------------------
【全新 v1.4 核心升级特性】
1. 🎨 macOS 26 视觉美学重构与彻底消除文字截断/堆叠 Bug：
   - 彻底修复设置窗口中文字显示不全与重叠堆叠的问题：
     • 废除底层硬编码文本长度，全面引入动态测量与智能自动换行；
     • 严格分离复选框控件与说明文本的物理图层，杜绝控件遮挡文字；
     • 窗口宽度扩展至 680px 舒朗宽屏视野，彻底消除右侧数值与控件挤压出界的现象。
   - 胶囊分栏（Segmented Capsule Tabs）与 Inset Grouped 卡片化排版全面升级，
     深浅色主题自适应与 DWM 原生圆角呈现极致通透美感。
   - Direct2D 实时准星仿真预览升级为全宽画卷卡片，毫秒级响应尺寸与留白调整。

2. ⚡ 单快捷键智能复用（Show/Hide + Exit Toggle）：
   - 单键兼顾显示与退出：显隐热键与退出热键支持设为【完全相同的按键组合】！
   - 智能分发逻辑：
     • 当十字线未显示时：按下快捷键即刻显示十字线并重载配置；
     • 当十字线已处于显示状态时：按下同一快捷键即刻安全退出程序。
     无需记忆两个独立按键，只需一键即可完成全部控制！

3. 🎹 按键按下顺序完全无关（Order-Independent Modifiers）：
   - 无论您先按下 Shift 还是先按下 Alt / Ctrl / Win，只要修饰键处于按下状态
     并敲击触发键（如 E 键），系统均能毫秒级精准触发，彻底告别按键死板顺序限制。
   - 配置文件中同时完美兼容 + 与 , 分隔符（如 Shift+Alt 与 Shift,Alt 等价解析）。

4. 🎨 极简加粗激光十字标与中心圆孔镂空图标：
   - 钛金磨砂渐变微弧底座，4个圆角外保持 100% 数学 Alpha=0 纯透明（绝无黑边与黑晕）。
   - 十字线大幅加粗至 16px，中心加入精致的圆形镂空孔径，在浅色/深色壁纸及任务栏中均清晰可辨。

5. 📐 最大 8K 分辨率与高 DPI 屏幕动态自适应 (High-DPI & 8K Ready)：
   - 内置 PerMonitorV2 顶级 DPI 感知清单。
   - 十字线粗细与间隙自动根据当前显示器的物理微米级 DPI 进行动态比例缩放。
     即使在 4K/8K 超高清电竞屏上，线条依然保持一致的视觉比例与清晰度，拒绝变成肉眼难辨的单像素细丝。

6. 🚀 启动显隐状态自定义 (Show on Startup Toggle)：
   - 【默认优化为启动不显示】：打开软件后将静默常驻系统右下角托盘，保持桌面干净整洁，随时按下 Shift + Alt + E 或单击托盘图标呼出；
   - 在偏好设置「系统与更新」分栏中勾选「启动软件时显示十字辅助线」可恢复打开即显示的经典模式。

7. 🚀 绿色开机自启动支持 (Auto-Start)：
   - 在偏好设置窗口中一键勾选“开机自动启动”，由当前用户的 HKCU 注册表独立接管。
   - 绿色纯便携，无需管理员权限，关闭选项即刻彻底清除，不留任何残留。

8. 🔄 原生一键本地直接更新 (One-Click Direct Auto-Update)：
   - 无需跳转浏览器去 GitHub 手动下载：检测到新版本时，弹窗提供【是 (一键直更)】选项。
   - 软件将在后台极速下载最新版本、原地安全热替换、并自动平滑重启完成升级，免手动解压搬运！
   - 同时保留【否 (前往网页下载)】选项，满足多样化使用习惯。

-----------------------------------------------------------
【默认交互快捷方式】
• 切换显隐快捷键：Shift + Alt + E（可在设置中自定义，支持与退出设为同一键）
• 退出程序快捷键：Shift + Alt + Q（可在设置中自定义，支持与显隐设为同一键）
• 鼠标托盘操作：
  - 单击托盘图标：快速切换十字线显示 / 隐藏
  - 双击托盘图标：打开 macOS 26 分栏胶囊偏好设置面板
  - 右键托盘图标：呼出功能菜单（设置、检查更新、重载配置、退出）
